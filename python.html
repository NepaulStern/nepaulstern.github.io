The Nepaul-Stern Model in Python

The Nepaul-Stern Model of Attitude Stability and Constraint is for panel surveys that ask the same people the same attitude questions more than once. The answers are on Likert scales (strongly agree to strongly disagree, liberal–conservative, party identification). Several related attitudes are measured together. Waves may be unevenly spaced, and a person may miss a wave or leave an item blank. Covariates such as age or education can be included.

The questions are about stability (how firmly an attitude persists), constraint (how much one attitude moves with another), how much of the variation comes from lasting individual differences, short-run change, and measurement noise, how a shock to one attitude spreads across later waves, and how covariates relate to the attitudes. Nepaul and Stern (2026) discuss the General Social Survey results. This page is about estimating the model.

Install

You need Python 3.10 or newer. Ready-made installs are provided for Python 3.10, 3.11, 3.12, and 3.13 on Linux (64-bit Intel and 64-bit ARM), macOS (Apple silicon and Intel), and 64-bit Windows. On those systems you do not need a compiler. The install also brings in NumPy, SciPy, and pandas.

If you need to build from source

On a computer without a ready-made install, the same command compiles the package. You need Python 3.10 or newer, a C++17 compiler, and CMake, which the installer uses to compile the program.

A survey of your own

Put the survey in a data frame with one row per person per wave. Name the person column and the wave column in id_col and wave_col. Code each Likert item as the integers 1, 2, 3, and so on, with no skipped code. Leave a skipped item as missing. If someone misses a wave between their first and last interview, keep a row for that wave so the attitude can be carried across it.

For a new sample, use 50 draws. The default is 10, which is what the General Social Survey replication uses. threads is how many processors to use. Changing it changes the waiting time. The estimates stay the same. seed=1 is the default.

The formula adds an intercept. That is what you want when every row is a real interview. The General Social Survey example already has an intercept column, so the call sets add_intercept=False and lists that column with the covariates.

The prepared items are ideology (7 categories), military (3), welfare (3), immigrants (5), party (7), and environment (3). The file has 11,282 people. The loader returns 22,443 rows, and 11,252 people have a positive weight and enter the likelihood. These are the first rows of that data frame.

maxit=0 evaluates the replication starting values and returns. draws=10 and seed=1 are the defaults used for this replication: ten simulated paths, each paired with its mirror image (antithetic draws). On 4 threads that evaluation takes a few seconds.

A full search from those starting values took 276.3 seconds in Python on 4 threads. It stopped with convergence code 0 at log-likelihood -111545.0088160454. The tables on this page are the evaluation. summary() prints its log-likelihood as -111570.970223.

Persistence and impulse responses

persistence_matrix() is on a scale from −1 to 1. The row receives the lag. The column is the attitude that is lagged. impulse_response(horizon=8) follows a one-unit shock. Horizon 0 is the identity. For this fit the spectral radius is 0.6366776792122704. The rows below are the ideology responses at horizons 0 and 1. The figure is the full grid. Nepaul and Stern (2026) discuss what the paths mean.

Variance decomposition

variance_decomposition() reports four pieces for each latent attitude. covariate is the variance of the wave effect plus the covariates. wave_effect is the wave effect on its own. factor is the sum of squared loadings, the part that stays with the person across waves. shock is the average short-run contribution built from the persistence coefficients. total adds the four.

Predicted categories and a new panel

predict(type="class") is the Likert category with the highest probability. type="prob" is one row per person, wave, attitude, and category. The probability excerpt is ideology. The small draw count is the setting that produced this excerpt. The default uses at least 20 draws.

simulate() draws a new panel from the fitted coefficients, with 11,252 people and 8 waves (90,016 rows). Covariates other than the intercept are standard normal. The intercept column is left off, so the frame can be passed back to fit with add_intercept=True. The printed rows use seed 2.

The corner of the stored covariance matrix

summary() uses the covariance stored with the fit. Here that is opg_centered. This is the corner of that matrix.

How it works, briefly

The arithmetic is done by a C++17 program that has no libraries of its own. The Python package calls that same program, so a fit lines up with the R package.

The likelihood is simulated, by the Geweke–Hajivassiliou–Keane (GHK) method. The slope of the likelihood is analytic, and the default search uses BFGS, the same steps the R package takes. L-BFGS-B and Nelder-Mead are also available.

The random draws use Philox. Each draw is tied to the seed, the person, and the draw number, so the same data and seed give the same answer with any number of threads, and on Windows, macOS, and Linux. The seed does not change NumPy’s random numbers.

The loop over people can use several threads. Standard errors can be the outer product of the person-level scores (the default, opg_centered, or the uncentred opg), the curvature of the likelihood (hessian), or the sandwich combination of those two.
